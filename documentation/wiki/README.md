# GitHub wiki pages (source)

These files are the source of the project's GitHub wiki (https://github.com/minhajuddinm/vox/wiki). The wiki is a short, friendly front door; the full and checked documentation stays in `documentation/`, and wiki pages link there instead of repeating it.

To publish: create the first wiki page once in the GitHub web UI (this creates the wiki's git repository), then copy these files (all except this README) into a clone of `https://github.com/minhajuddinm/vox.wiki.git` and push. Change the pages here first, in a PR, then publish.
